Política de Privacidade

Aplicativo: Finanças Pessoais (uso pessoal, um único usuário: o próprio desenvolvedor).

O que o aplicativo acessa

Com a permissão somente leitura do Gmail (gmail.readonly), o aplicativo lê apenas e-mails promocionais de remetentes específicos (programas de milhas e de cartões), escolhidos na própria busca. E-mails de outros remetentes não são baixados. O aplicativo nunca envia, apaga, move nem altera e-mails.

Como os dados são usados

  • O texto desses e-mails promocionais é processado no servidor doméstico do desenvolvedor para identificar ofertas (programa, bônus, validade).
  • Para extrair esses campos, o texto do e-mail promocional pode ser enviado à API de um serviço de inteligência artificial (OpenAI), apenas para esse fim. Os dados não são usados para publicidade nem para treinar modelos.
  • Os dados não são vendidos nem compartilhados com terceiros, exceto o envio descrito acima.

O que fica armazenado

Apenas o assunto do e-mail, o link para ele e os campos extraídos da oferta, no banco de dados do servidor doméstico. O corpo dos e-mails não é guardado.

Conformidade com as políticas do Google

O uso e a transferência, a qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
